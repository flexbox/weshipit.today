### 🟦 RN Chunk 1 — Run a New Architecture readiness audit

**Goal:** Identify the concrete migration work needed to improve startup, stability, and performance without deciding to rewrite the app natively.

**Source:** [Shopify native migration case study](https://shopify.engineering/back-to-native)

**Scope:**
- Audit inventory legacy-architecture dependencies and native modules.
- Audit measure one startup and one stability baseline.
- Audit list blockers that prevent New Architecture adoption.
- Audit create a prioritized remediation backlog with one small quick win.

**Out of scope:** A native rewrite, a full migration, and attributing all performance issues to React Native without measurement.

**Dependencies:** Access to the app's native dependency graph and one representative release build.

**Acceptance criteria:
- [ ] The audit names each blocker and its owning package or app module.
- [ ] Startup and stability baselines are reproducible.
- [ ] The team has one prioritized remediation suitable for a one-day follow-up.
- [ ] No production architecture switch is made by this chunk.

**Estimated effort:** M
